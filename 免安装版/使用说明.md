# Pudiu 大数据分析可视化工具 v4.1 · 使用说明

本地运行的被动抓包与数据提取工具：你在浏览器里正常访问网页，它记录每个请求的明文请求头/Cookie/请求体、响应头/响应正文，实时筛选；还能按规则从响应 JSON 里自动提取字段生成地址，翻页时自动累积统计。

---

## 一、界面结构（v4 全新视觉）

左侧六个入口：

| 入口 | 作用 |
|---|---|
| **总览** | 实时统计卡片、诊断计数、快速上手、最近生成结果 |
| **抓包** | 请求列表 + 详情面板。点地址看响应，点「查看」全屏看 |
| **规则** | 字段提取规则编辑、样例响应字段选择、试运行验证 |
| **结果** | 自动生成的地址列表，勾选/分页/复制/导出；点地址直接看来源响应 |
| **工具** | 内置数据处理工具箱 + 外部程序联动 |
| **导航** | 数据分析 / 可视化工具导航：分类浏览、搜索、看详情、一键打开（v4.1 新增） |
| **设置** | 抓正文开关、跟随最新、主题、每页条数、目录入口 |

顶部还有一条**预设网址书签**：默认只有 `https://tool.pudiu.com/` 和 `https://bing.com`。点一下即在抓包浏览器里打开；点「✎ 管理」后按「标题 + 网址」填写即可增删改，保存在 exe 同目录 `bookmarks.json`。

**界面细节**：
- 窗口带渐变顶边、圆角外框与柔和阴影，启动即按屏幕工作区（排除任务栏）计算尺寸和位置，保证整个窗口在屏幕内。
- 自己启动的 Chrome 也带 `--window-position/--window-size` 参数，不会跑到屏幕外。
- v4 修复启动时序：界面等内部接口就绪后才初始化，彻底解决「点了没反应 / 预设网址与规则不显示 / 点地址看不了响应」这类问题。

## 二、两种启动方式

### 方式 A：工具自己开 Chrome（默认）

1. 双击 `Pudiu大数据分析可视化工具.exe`
2. 点顶部 **「▶ 开始抓包」** —— 弹出一个 Chrome 窗口（位置尺寸已按屏幕计算）
3. 在**那个窗口**里正常访问网页、登录、翻页
4. 点 **「■ 停止抓包」** 关闭；再点一次重新开始

> 独立配置，不影响你平时的 Chrome 登录态；第一次需要重新登录目标网站。

### 方式 B：附加已开的调试 Chrome（用已登录的浏览器）

普通双击打开的 Chrome 没有调试端口，外部程序读不到它内部已解密的数据——这是浏览器安全边界，不是工具的问题。

1. 双击本文件夹的 **`以调试模式启动Chrome.bat`**
   - 会自动读取屏幕工作区并计算窗口位置尺寸，保证 Chrome 窗口在屏幕内
   - 端口 9222，独立配置目录 `%LOCALAPPDATA%\PacketCapChrome`
   - 第一次在这个窗口里登录目标网站，之后登录态保留
2. 回到工具，端口保持 `9222`，点 **「附加已开浏览器」**
3. 点 **「■ 停止抓包」** 只断开连接，不会关闭你的 Chrome

> 如果你自己用 `--remote-debugging-port=xxxx` 启动了 Chrome，把端口改成 xxxx 再点附加。

## 三、查看 / 复制 / 编辑响应数据（v4 增强）

- **点请求列表里的地址**（蓝色路径）→ 右侧详情面板显示响应正文。
  这里会**回源重新取一次最新详情**，解决轮询快照里正文还是空的问题。
- **点该行「查看」按钮** 或详情里的 **「全屏查看」** → 打开大窗口，方便看长 JSON。
- 响应正文支持：
  - JSON 语法高亮（自动格式化）
  - 搜索框输入关键词高亮全部匹配，显示匹配数
  - 复制响应 / 复制为 cURL / 保存正文到 exe 同目录
  - **「重新取正文」**：CDP 偶尔取不到正文时手动补取；比「重新处理历史」更精准
- 详情还有 **请求正文 / Cookie / 请求头 / 响应头** 四个标签。

**鼠标选中即复制（v4 新增）**：
- 列表单元格、详情正文/头部、Cookie 值、生成地址都可以用鼠标拖选文字；
- `Ctrl+C` 直接复制，选中文字后还会浮出「复制选中」按钮点一下复制；
- 轮询刷新时若你正在拖选文本，会自动暂停重绘，选区不会被冲掉。

**点击编辑（v4 新增）**：
- 详情里点 **「✎ 编辑内容」** → 出现多行编辑框，改完点「保存修改」；
  之后「复制响应」「保存正文」「导出」都使用你改过的版本。
- 「结果」页点任意生成地址，右侧头部点 **「✎ 编辑」** 可直接改生成地址，改完复制/导出同步更新。
- 手动修改只在**本次运行**内有效，重启程序会以抓到的原始数据为准；需要长期保存请用「保存正文」/「导出」。

## 四、Cookie 记录

- 请求列表 **CK** 列显示 Cookie 数量；筛选栏勾 **带Cookie** 只看含 Cookie 的请求。
- 详情 **Cookie** 标签分两组：
  - 请求携带的 Cookie：名称、值、Domain、Path、HttpOnly / Secure
  - 响应下发的 Set-Cookie（登录态通常在这里）
- 关键词搜索也会搜 Cookie 的名和值；详情里可一键复制 JSON。

## 五、按响应字段自动生成地址

像 `url.pudiu.com/post` 的 JSON 提取器，但全自动：设置一次，翻页抓到响应就自动提取、拼地址、累积统计。

### 设置（新增试运行）

1. 先在「抓包」页点一条**有 JSON 响应的请求**（比如公告列表接口）。
2. 切到 **「规则」** 页，它会自动成为**样例响应**；下拉框可换其他响应。
3. 样例响应下方的字段按钮，点一下就填入当前编辑规则的「目标字段名」——不用手打。
4. 填规则：

| 字段 | 说明 | 示例 |
|---|---|---|
| 规则名称 | 方便识别 | 公告详情地址 |
| 接口 URL 关键字 | 只处理 URL 含此关键字的响应；逗号分隔多个；留空=全部 | `findNoticesBynotices` |
| 目标字段名 | 递归扫描响应 JSON 里所有同名字段 | `id` |
| 请求方法 | GET / POST / 不限 | POST |
| 前缀 / 后缀 | 拼在字段值前后 | `https://www.crccep.cn/findNotices?noticeId=` |
| 自动去重 | 相同地址只记一次 | 勾选 |

5. 点 **「试运行」**：立刻显示这条规则在样例响应上提取到了哪些值，不对就改字段/关键字。
6. 规则实时自动保存，也可点 **「保存规则到文件」**。配置文件是 exe 同目录 `rules.json`，复制到另一台电脑即可迁移规则。

### 使用

- 回「抓包」页翻页，命中的响应会自动累积到「结果」页。
- 结果页支持：按规则筛选、关键词筛选、分页（20/50/100/200）、勾选后复制选中、复制全部、清空。
- 导出 TXT（一行一个，直接粘贴）/ Excel / CSV / JSON。
- 改了规则后点 **「重新处理历史」**，对已抓到的响应回填并补取漏掉的正文。

## 六、诊断：翻页后结果为 0

「结果」页底部诊断条显示：请求 / 响应 / 有正文 / 正文失败 / 命中规则 / JSON成功 / 非JSON / 字段未找到 / 生成。

| 现象 | 原因 | 处理 |
|---|---|---|
| 命中规则 = 0 | 接口关键字或方法写错 | 在抓包页看真实 URL/方法，改规则 |
| 命中规则 >0、JSON成功 = 0 | 该接口返回的不是 JSON | 看不到字段就没法提取 |
| JSON成功 >0、字段未找到 >0 | 字段名不对 | 用规则页的字段按钮直接选 |
| 正文失败 >0 | 缓存/响应太大/时序 | 点详情页「重新取正文」或「重新处理历史」 |
| 请求数没增加 | 页面数据来自缓存，没发新请求 | 浏览器里 Ctrl+F5 强制刷新再翻页 |

## 七、筛选与导出

- 抓包列表：关键词（URL/正文/Cookie）、域名、方法、状态码、资源类型、只看接口、只看带 Cookie，可叠加；点列头排序；分页 50/100/200/500。
- 导出 Excel / CSV / JSON / HAR（HAR 可导入 Fiddler/Charles），导出的是**当前筛选结果的全部页**。
- 「设置」页可切换浅色/深色主题、关闭正文抓取、调整跟随最新与每页条数；偏好保存在本机。

## 八、预设网址、工具导航与数据处理工具箱

### 预设网址书签

- 顶部「预设网址」默认只有两个：**tool.pudiu.com**、**bing.com**；点名字即在**抓包浏览器**里打开。
- 点「✎ 管理」打开编辑窗口，每行只填**标题 + 网址**两个框，点「保存」即可；网址留空的行自动忽略。配置保存在 exe 同目录 `bookmarks.json`。

### 工具导航（左侧「导航」页）

收录 19 个推荐的数据分析 / 可视化在线工具，按 **数据分析平台 / 可视化图表 / 数据清洗转换 / 文本与正则 / 接口与抓包 / 效率工具** 分类：

- 顶部搜索框可按名称、说明、网址过滤；分类按钮可快速切换。
- 左侧点任意工具卡片，右侧显示**简介、访问地址、使用建议**。
- 详情里的「在系统浏览器打开」「在抓包浏览器打开」「复制网址」可直接使用。
- 「＋ 添加工具」可录入自己的常用工具（名称、网址必填，分类/简介/建议可留空）；「恢复推荐清单」可一键还原内置列表。配置保存在 exe 同目录 `navtools.json`。

内置清单包括：Pudiu 工具箱、Pudiu JSON 字段提取、Flourish、Datawrapper、RawGraphs、ECharts 示例、Chart.js 示例、Highcharts Demo、Plotly Chart Studio、Observable、阿里云 DataV、ConvertCSV、JSON.cn、JSON Viewer、站长工具、Regex101、RegExr、Hoppscotch、Bing 搜索。

### 内置数据处理工具箱（左侧「工具」页）

先把文本粘到「① 输入文本」（可点「粘贴选中/剪贴板」「用当前详情响应」「用全部生成地址」直接载入），
在「② 选择处理工具」里点一个工具，点「▶ 执行处理」，结果出现在右侧：

| 工具 | 作用 |
|---|---|
| JSON 格式化 / 美化 | 缩进排版，便于阅读 |
| JSON 列出全部字段名 | 递归列出所有 key |
| JSON 按字段名提取值 | 输入字段名，递归取出所有同名字段的值 |
| 正则提取 / 替换 | 填正则与替换模板，`$1` 表示分组 |
| 批量加前后缀 | 每行文本前/后拼接固定字符串 |
| 去重 + 排序 | 去空行、去重、自然排序 |
| 提取文本里的网址 | 从任意文本中抓出 http(s) 地址 |
| 按行拆分 / 合并 | 清理空白行 |
| Base64 编码 / 解码 | 中文也可正确处理 |
| 统计行数 / 字数 | 行数、非空行、字符数、字节数 |

结果可复制、保存为文件；抓包详情按钮「送入工具箱」、结果页「送入工具箱」都能直接把数据带过来。

### 外部程序联动与一键打开

- 「工具」页右下角「外部程序联动配置」：新增工具填**名称**和**命令模板**，模板里
  `{file}` 代表临时文件路径、`{text}` 代表文本前 500 字。
  例如 `notepad.exe {file}`、`python {file}`。点「保存外部工具配置」写入 `tools.json`。
- 工具列表里带 ⚙ 标记的即外部工具，选中后点「▶ 调用外部程序」即可把输入文本送出去。
- 结果页点一条生成地址，右侧可 **「在系统浏览器打开」**、**「在抓包浏览器打开」**、
  **「送入工具箱」**；勾选多条后可「批量打开选中」（最多 20 个，防止误开太多）。

## 常见问题

**Q：HTTPDebugger 抓不到那个网站的 HTTPS，这个能抓吗？**
A：能。让 Chrome 自己解密再从浏览器内部读明文，不装证书、不改系统代理。

**Q：直接打开平时的 Chrome 访问网页，为什么抓不到？**
A：那种 Chrome 没开调试端口，浏览器不允许外部读取明文。请用「方式 B」，先跑 `以调试模式启动Chrome.bat`。

**Q：exe 旁边的 `rules.json` / `startup.log` 能删吗？**
A：`rules.json` 是保存的规则，删了规则就没了；`startup.log` 是运行日志，可删。

**Q：首次运行弹出防火墙提示？**
A：勾选允许。程序只在本机运行，附加模式只连本机调试端口。
